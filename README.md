# how-conv-work

합성곱(Convolution)은 실제로 무엇을 하는가 — "뒤집고, 밀고, 곱하고, 더한다"의 수학적 의미를 브라우저에서 직접 실험하며 배우는 인터랙티브 교육 자료입니다.

**🔗 데모: https://dev-jonghoonpark.github.io/how-conv-work/**

> [how-ai-works](https://github.com/dev-jonghoonpark/how-ai-works) 시리즈의 일부입니다.

## 다루는 내용

| 절 | 주제 | 인터랙티브 데모 |
|---|---|---|
| §1 | 수학적 정의 — 뒤집고·밀고·곱하고·더하기 | — |
| §2 | 1D 합성곱 기계 | 슬라이더로 커널을 밀며 자리별 곱·합을 직접 확인, 뒤집기 on/off |
| §3 | 합성곱의 네 가지 얼굴 (가중평균 · 시스템 응답 · 확률 · 주파수) | — |
| §4 | LTI 시스템과 임펄스 응답 — 합성곱이 어디에나 나타나는 이유 | 클릭으로 임펄스를 놓고 중첩 원리 관찰 |
| §5 | 확률분포의 합성곱과 중심극한정리 | 주사위 개수를 늘려 종 모양으로 수렴하는 분포 |
| §6 | 합성곱 정리 ℱ(f∗g) = ℱ(f)·ℱ(g) | 실제 DFT로 스펙트럼 곱 = 출력 스펙트럼 검증 |
| §7 | 2D 이미지 합성곱 | 3×3 커널 편집(블러·샤픈·Sobel), 출력 픽셀에 마우스를 올리면 계산 과정 표시 |
| §8 | CNN — 파라미터 공유·등변성·지역성, 스트라이드/패딩 | 출력 크기 공식의 슬라이딩 윈도우 애니메이션 |
| §9 | 이해도 퀴즈 | 6문항 |

## 실행

빌드 과정 없는 단일 `index.html`입니다. 브라우저로 열면 됩니다.

```bash
open index.html
```
